# TrueUp

Payment reconciliation and double-entry ledger platform with AI-assisted matching.

[![CI](https://github.com/Karansahni18/trueup/actions/workflows/ci.yml/badge.svg)](https://github.com/Karansahni18/trueup/actions/workflows/ci.yml)

**Status:** in development (Step 1: repository skeleton)

## Problem
Businesses selling through payment providers receive payouts that never match
their bank deposits: fees are deducted, refunds arrive late, and batches combine
transactions. TrueUp ingests provider events and bank statements, records
everything in a balanced ledger, and reconciles them automatically.
